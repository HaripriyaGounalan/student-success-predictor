# student-success-predictor
An AI-powered student analytics and prediction platform designed to explore academic performance and identify factors influencing student success.

The application combines interactive data exploration with machine learning models to predict **GPA, first-year persistence, and program completion**.

## Key Features

- Interactive student data exploration and correlation analysis
- GPA prediction
- First-year persistence prediction
- Program completion prediction
- Model performance and training insights
- User-friendly prediction dashboard

## Tech Stack

**Python · Machine Learning · Streamlit · Pandas · Scikit-learn · Data Visualization**

## Application
The dashboard provides an end-to-end workflow from data exploration to individual student outcome prediction, with model metrics and visual insights presented alongside each prediction.
